# Features

- Trance Music lover trying to make Software synth...
- A Synth that has 4 of Oscillator, Saw, 
  Supersaw Wave, Sine Wave, Square Wave, 
  FM, Filter, 2 Envelope(for volume and filter), 
  Reberb, and Delay...
- I using JUCE freamwork
